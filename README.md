# Menta Lesson Planner

**Menta Lesson Planner**: a free Claude plugin for language teachers. One sentence in, a 60-minute interactive
lesson out: clickable exercises, translations on tap, pictures, unit tests, print / PDF.

Website: https://menta-lms.com/plugin

## Install
**Claude Code**
```
/plugin marketplace add illiaKvanette/menta-lesson-planner
/plugin install menta-lesson-planner@menta
```
**Claude app (web and desktop)**: download https://menta-lms.com/lesson-planner-skill.zip, then
Settings → Capabilities → Skills → Upload skill.
